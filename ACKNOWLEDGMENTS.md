# Acknowledgments

Dual Screen Mode is made by slinky.

This project is a small packaging and configuration layer around existing tools
and community knowledge. It does not replace or claim ownership of the work
that makes the setup possible.

- KDE Plasma and `krfb-virtualmonitor` provide the virtual display.
- Sunshine by LizardByte provides host-side game streaming.
- Moonlight provides the handheld-side client.
- Community guides and troubleshooting discussions helped identify the
  repeatable KDE Wayland setup that this project packages.

The goal here is simple: collect the useful pieces, explain the setup plainly,
and make the result consistent and easy to turn on and off.
