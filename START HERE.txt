DUAL SCREEN MODE
Beta release 0.1.3

START HERE

1. Extract this archive.
2. Double-click: Install Dual Screen Mode.desktop
3. Press Begin setup in the wizard to launch the installation.

That is the only file you need to launch for a normal installation.

After setup, two shortcuts are created on the Desktop:

- Dual Screen Mode turns the virtual display on or off.
- Dual Screen Mode Settings shows status, settings, help, updates, and uninstall.

Moonlight is installed separately on the handheld. Pair Moonlight with
Sunshine manually through their normal pairing flow, then use the Dual Screen
Mode shortcut on the host whenever you want the virtual display.

The other files are the readable source code, documentation, and artwork. Do
not launch the internal .sh or .py files manually unless you are inspecting or
developing the project.

If the desktop file does not launch, open a terminal in this folder and run:

    ./launch-wizard.sh
